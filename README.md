# 🚀 StockSphere – FMCG Inventory & Sales Management System

StockSphere is a full-stack FMCG inventory and sales management platform designed to streamline inventory tracking, billing, order management, delivery monitoring, and business analytics through a centralized digital system.

The project addresses common challenges in traditional inventory systems such as manual stock handling, billing errors, delayed updates, and inefficient order processing. StockSphere provides an integrated and scalable solution for retailers, wholesalers, and administrators through role-based dashboards and automated workflows.

---

# ✨ Features

## 👨‍💼 Admin Dashboard

* Manage products and inventory
* Add, update, and delete product records
* Process and monitor orders
* Manage delivery status and billing
* Analyze revenue using date-based filtering
* Monitor top customers and sales insights
* Auto-restock products when stock is low
* View business analytics and transaction history

## 🛒 Retailer Dashboard

* Browse products with pricing and stock details
* Search and sort products
* Place orders directly from the dashboard
* Automatic bill generation
* Track order history and spending
* Export reports in CSV format
* View payment and billing records

## 🚚 Wholesaler Dashboard

* Track deliveries and pending orders
* Monitor sales trends and top-selling products
* Manage delivery updates
* Access analytics dashboards
* Export operational reports

# 🗂 Database Design

The system follows a relational database architecture using SQLite with normalized tables for:

* Products
* Customers
* Orders
* Order Details
* Payments
* Deliveries
* Retailers
* Suppliers
* Wholesalers

The database is normalized up to Third Normal Form (3NF) to reduce redundancy and improve data consistency.

# 🚀 StockSphere AI

### Smart FMCG Inventory & Sales Intelligence Platform

StockSphere AI is a modern inventory and sales intelligence platform designed to simplify and optimize FMCG business operations through smart inventory management, automated billing, delivery tracking, and real-time analytics.

Built to solve the challenges of traditional inventory systems, StockSphere AI provides a centralized and scalable ecosystem for retailers, wholesalers, and administrators to efficiently manage products, orders, sales, and operational workflows.

---

# 🌟 Core Features

## 📊 Admin Control Center

* Manage products, inventory, and stock levels
* Add, update, and remove product records
* Monitor and process customer orders
* Manage delivery workflows and billing systems
* Analyze revenue using dynamic date-based insights
* Track top-performing customers and products
* Automated low-stock restocking system
* Access centralized business analytics and transaction history

## 🚚 Wholesaler Dashboard

# 🧠 System Architecture

StockSphere AI is designed using a relational database architecture with normalized data structures to ensure scalability, consistency, and efficient business operations.

### Core Database Modules

* Products
* Customers
* Orders
* Order Details
* Payments
* Deliveries
* Retailers
* Suppliers
* Wholesalers

The database follows **Third Normal Form (3NF)** principles to minimize redundancy and maintain high data integrity.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone <repository-link>
cd stocksphere-ai
```

## Install Dependencies

```bash
npm install
```

## Start Server

```bash
node server.js
```

## Run Application

Launch the frontend using Live Server or your preferred local development server.
